# 아스테리아 — 문서 인덱스

> 진입점. 어디부터 볼지, 새 문서를 언제 만들고 언제 지울지를 여기서 잡는다.
> 원칙: **문서는 기억상실 방지 + 스콥크립 차단을 위한 도구다. 이 둘을 못 하는 문서는 지운다.**

## 문서 규칙 (추가·삭제 기준)

문서는 30분 써서 3개월 참고하면 성공, 그 이상은 개발 시간을 훔친 것이다.

- **새 문서는 위 둘 중 하나를 할 때만 만든다** — ① 미래의 내가 잊을 결정을 붙잡거나(기억상실 방지), ② 범위가 새는 걸 막거나(스콥크립 차단). 둘 다 아니면 코드 주석이나 기존 문서 한 줄로 끝낸다.
- **범위를 넓히려면 → [DecisionLog](working/DecisionLog.md)에 기록 + [GDD](working/GDD_Asteria.md) "있을 것"에서 하나 뺀다.** 넣기만 하는 건 스콥크립이다.
- **하지 마라:** 50페이지 명세, 모든 시스템 선(先)상세화, 완벽한 문서 먼저·개발 나중, 설정 놀이.
- **분기 리뷰:** [GDD 범위 경계]를 다시 읽고 — 넘었으면 [DecisionLog]에 기록하고 무엇을 뺐는지 확인한다.
