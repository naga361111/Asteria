> 최상위 문서. "무엇을 / 어디까지"만 잡는다. 시스템 원리는 바이블 참조:
> [세계관·시스템](../bible/Asteria_World_Setting.md) · [마법](../bible/Asteria_Magic_System.md). 왜 그렇게 정했는지는 [결정 로그](DecisionLog.md).

> `❓` = 아직 안 정한, **네가 정할 자리**. 채우지 않고 비워뒀다.

## 1. 엘리베이터 피치
> 스크립트 없이 주민들의 하루가 스스로 굴러가는 마을 시뮬레이션 RPG. 플레이어는 이 톱니바퀴에 던져진 변수로서, 주민을 관찰하고 그들의 일과를 거들며 마을이 재해를 견디게 만든다. 정해진 엔딩은 없고, 실패(마을 붕괴)만이 유일한 종료다.

## 2. 코어 루프
> **관찰**(NPC 동선·감정) → **개입**(일과 거들기: 농사·채집·가공·전투, 유기적 의뢰 수락) → **성장**(친밀도 ↑, 자기 숙련도 ↑) → 그 숙련도가 곧 **마을의 재해 대처 역량**이 됨.
> 시간 축: 현실 1시간 = 게임 1일, 낮은 무스킵.

## 3. 범위 경계 ← **제일 중요**

### 있을 것 (아래 컷 리스트 P0~P1 참조)
효용 기반 NPC AI · 욕구/4기둥 · 친밀도 · 소문 전파 · 유기적 의뢰 · 전투 · 숙련도 · 마을 항상성(승계) · 사건(작은/큰) · 마법.

### 없을 것 (성역 — 바이블에서 "안 한다"고 못 박음. **왜·상세는 [결정 로그](DecisionLog.md)**)
- **멀티플레이** (§2·§7)
- **오픈월드** · **지하 폐광** (§8)
- **보이스/컷씬**
- 마법 **창조** — 마법서로 습득만 (마법 §2)
- 느낌표/스크립트 **고정 퀘스트** — 동적 의뢰만 (§6)
- **정해진 해피엔딩·승리 조건** — 실패 종료만 (§11)
- NPC **노화·세대교체** — 사망/이탈 교체만 (§9)
- **NPC 수백 명 규모** — 현 단계 수십명 고정 (§5)
- **방치형/오프라인 연산** — 종료 시 시간 동결 (§2)
- 사건 **전조·예고** / 플레이어발 사건 **제안** (§10)
- 플레이어 **사망** — 기절 → 며칠 손실만 (§12)
- 영창의 **실제 효과** — 헛소문 설정 (마법 §3)
- **무마력자** 시스템 — 설정만, 현 단계 미구현 (마법 §1)

### 변경 프로토콜
경계를 넘고 싶으면 → **결정 로그에 기록 + 있을 것에서 하나 뺀다.** 넣기만 하는 건 없다.

## 4. 아트 / 사운드
❓ — 바이블에 방향 없음. 참고 이미지·음원 링크 3~5개로 "이런 느낌"만 나중에 채우기.

## 5. 마일스톤 (날짜 아님, **산출물**)
바이블에 흩어진 단계 힌트를 산출물로 정리. **NPC 규모 = 수십명 고정.**

- **MVP**: 소수 NPC가 효용 AI로 하루를 자율로 살고, 플레이어가 일과 하나를 거들어 친밀도·숙련도가 변한다. 코어 루프 1회전.
- **버티컬 슬라이스**: 위 + 작은 사건 1종 + 유기적 의뢰 + 전투 + 밤의 소문 전파가 처음부터 끝까지 물린다.
- **1.0**: 컷 리스트 P0+P1 전부 플레이 가능. NPC 수십명 규모.

## 컷 리스트 (우선순위 → 버전)

바이블의 시스템을 버전에 묶었다. **P 배정에 ❓ 붙은 건 네 결정 대기.**

| P | 시스템 | 버전 | 근거/메모 |
|---|---|---|---|
| P0 | 효용 AI(욕구·4기둥·행동점수) | 1.0 | 게임의 심장. 이거 없으면 아무것도 안 굴러감 |
| P0 | 친밀도 | 1.0 | 효용 공식의 관계 보너스 입력 |
| P0 | 전투 + 숙련도 | 1.0 | 성장·목표(§11)의 축 |
| P0 | 인벤토리 + 화폐(렌) | 1.0 | 거래·의뢰의 토대 |
| P1 | 소문 전파(Engram/Tavern Sync) | 1.0 | 나비효과의 전달 매체 |
| P1 | 유기적 의뢰(Dynamic Need) | 1.0 | 콘텐츠 생성 방식 그 자체 |
| P1 | 사건 — 작은 사건 | 1.0 | 창발 콘텐츠 |
| P1 | 마을 항상성 / 역할 승계 | 1.0 | 마을이 안 죽고 유지되는 근거 |
| P1❓ | 사건 — 큰 사건(붕괴의 시계) | ❓ | 게임 오버 축. 1.0 필수인지 슬라이스 이후인지 |
| P1❓ | 마법(마법서·농도·시전) | ❓ | 일상 필수 설정이지만 구현 비용 큼 → 어느 버전? |
| P2❓ | 계절(불숨/서리잠) | ❓ | 생산·사건 영향 미결(바이블 §2) |
| P2❓ | 후계자 / 외부 수혈 | ❓ | 항상성 보강. 1.0 승계만으로 충분한지 |
| P3 | "수백 명" 규모 확장 | 추후 | 현 단계 상한=수십명 고정, 증설은 별도 판단 |
| P3❓ | 신성 마법 / 숨겨진 흉터 해금 서사 | ❓ | 깊이 콘텐츠, 후순위 |
